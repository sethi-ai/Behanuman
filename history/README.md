# Be Hanuman — HTML to Next.js migration

Be Hanuman was originally developed as a standalone HTML application and later migrated to Next.js with Convex authentication and persistence.

The original HTML snapshot is preserved at `history/html-v1/index.html` solely as a migration reference, not as the current application entrypoint. It originally lived at `sethi-ai/promptsethi.com/BeHanuman/index.html` (source blob `c997d6aa52de6bb2d77e2a8b59902ff83b0d1717`).

Current public app: https://hanuman.dyut.si/
Original public HTML version: https://www.promptsethi.com/BeHanuman/

For reviewers: compare the original HTML interface with the current Next.js version. Do not treat this historical snapshot as the live source of the Next.js deployment.
